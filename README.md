# Markdown

The system home for markdown documents in the Cinatra artifact library. It accepts `text/markdown` and files it under a dedicated markdown type, so a `.md` file you attach in chat, upload to the library or hand to an agent lands correctly typed as markdown rather than as general text.

Install from the Cinatra marketplace by searching for "Markdown" and clicking **Add**. No credentials or configuration are required; the type is active immediately for all workspace members. This extension gives markdown its identity: one type, one name, one place in the library. Its two views — the full view and the compact one — are declared and published by the package but do not draw a document.

## Works with

- Cinatra chat — attach a `.md` document directly in any thread
- The artifact library — every markdown document under one type
- Agents that write markdown — their drafts file here

## Capabilities

- Accept `text/markdown` uploads as a dedicated artifact type
- Give every markdown document one identity across chat, the library and a review
- Declare and publish the markdown views through the package's own exports
